# FluentCAD

FluentCAD — разрабатываемая настольная CAD-программа для создания эскизов и твёрдых тел. Интерфейс построен на PySide6, трёхмерная сцена использует PyVista и VTK, а геометрические операции выполняются с помощью build123d и Open CASCADE.

Проект находится в разработке: часть инструментов и параметрической истории уже доступна, но функциональность и устойчивость работы ещё не соответствуют полноценным промышленным CAD-системам.

## Возможности

- Создание эскизов на базовых плоскостях и плоских гранях, работа с линиями, окружностями, дугами и другими элементами.
- Сетка и привязки при построении; поиск замкнутых контуров для операций с телами.
- Создание и изменение твёрдых тел, включая выдавливание, вращение, примитивы, скругления и фаски, перемещение, масштабирование и массивы.
- Ограничения и размеры эскиза, численный решатель и отображение состояния ограничений. Доступные связи зависят от режима редактирования.
- История операций и Undo / Redo; отдельный параметрический режим с зависимостями, именованными параметрами, выражениями и перестроением модели.
- Сохранение снимка модели в `.fcad`, импорт STEP, экспорт STEP и STL.

## Установка и запуск

Требуется Python 3.12 или новее. Проект разрабатывается и проверяется в Windows. Команды ниже выполняются в PowerShell из корневой папки проекта:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app\main.py
```

При установленном [uv](https://docs.astral.sh/uv/) зависимости можно установить из lock-файла:

```powershell
uv sync
uv run python app/main.py
```

Запускайте приложение из корневой папки проекта: некоторые ресурсы интерфейса загружаются по относительным путям. Точка входа `fluentcad` в текущем пакете пока является заглушкой; для запуска используйте `app/main.py`.

## Параметрическая модель и Timeline

В новом документе обычная кнопка **Create sketch** создаёт параметрический эскиз: выберите плоскость, нарисуйте геометрию и нажмите кнопку завершения эскиза. Замкнутые области появятся в сцене; щёлкните нужную область и нажмите **Extrude**, затем настройте операцию и подтвердите её. Эскиз и выдавливание появятся на Timeline. Чтобы повторно показать области эскиза, нажмите его правой кнопкой на Timeline и выберите **Show sketch profiles**.

Для редактирования существующего эскиза в основной сцене выберите в его контекстном меню **Edit sketch in scene**. Перетаскивайте синие именованные точки и оранжевые ручки радиуса окружностей; геометрия пересчитывается после отпускания мыши. Можно добавлять геометрию инструментами панели и задавать связи через **Constraints**. Кнопка завершения применяет изменения и перестраивает зависимые операции; Esc при неактивном инструменте отменяет редактирование. Редактор в отдельном окне пока сохранён как запасной вариант.

В группе **CREATE ▾** эскиза доступны **Bezier spline**, **Fit-point spline**, **NURBS** и **Periodic NURBS**. Задавайте точки щелчками в сцене: Безье завершается после четырёх точек, остальные — клавишей Enter. После завершения можно перемещать точки. Кнопка **NURBS parameters** открывает настройку степени, весов и узлов, а **Remove constraint** удаляет выбранную связь. Типы связей и элементы пока выбираются в диалогах по именам, не щелчками по геометрии.

Там же находятся команды **Polyline slot**, **Arc slot**, **Spline slot** и **Composite curve slot**. Настройки и связи применяются к копии эскиза в сцене: окончательное перестроение модели происходит при завершении эскиза, а Esc при неактивном инструменте отменяет изменения.

При работе с эскизом обычное перетаскивание левой кнопкой не вращает камеру. Для вращения удерживайте **Ctrl** и перетаскивайте левой кнопкой мыши; колесо по-прежнему управляет масштабом. После завершения эскиза восстанавливается обычная навигация сцены.

Эскиз на плоской грани параметрического тела хранит ссылку на эту грань. Если после перестроения грань нельзя однозначно найти, операцию нужно переопределить. Эллиптические дуги обычного эскиза сохраняются в параметрической истории.

Команда **FILE ▾ → Convert legacy model to parametric** переносит существующее тело старой модели в базовую неизменяемую операцию. Исходные эскизы и параметры операций из снимка восстановить нельзя; сохранённая история снимков доступна после отмены преобразования через Undo. Преобразованную модель можно сохранить в `.fcad` и добавлять к её телу новые параметрические операции.

Для поддерживаемых профилей выдавливание запоминает происхождение границ и ищет тот же контур после перестроения. Если соответствие не найдено или неоднозначно, изменение отклоняется. Чтобы назначить другой профиль после разделения контура, подавите выдавливание в Timeline, измените эскиз, выберите в контекстном меню выдавливания **Reselect extrusion profile**, щёлкните новый контур и снимите подавление. Это сопоставление не является полноценным устойчивым именованием топологии; для некоторых типов геометрии доступна только проверка количества профилей.

В группе **File** команда **New parametric model** создаёт пример: плоскость, прямоугольный эскиз и выдавливание с параметрами `width`, `height` и `depth`. **Edit named parameters** изменяет параметры, а **Add parametric feature** добавляет операцию и позволяет указать её параметры в JSON.

Контекстное меню операции на Timeline позволяет изменить параметры, переименовать, подавить или переместить операцию. Для эскиза типа `planar_sketch` с именованными точками доступны редактирование в сцене и отдельное окно. Изменения сначала проверяются перестроением модели и применяются после завершения редактирования.

В этом редакторе доступны связи совпадения, горизонтальности, вертикальности и фиксации точек, параллельности, перпендикулярности, коллинеарности и равенства длин отрезков, симметрии и середины, расстояния и угол. Для окружностей доступны радиус и диаметр, концентричность, равенство радиусов и касание к прямой или другой окружности. Для дуг по трём точкам доступны радиус, диаметр и касание в выбранной конечной точке к отрезку, другой дуге или окружности. Сопряжение по кривизне поддерживается в выбранных конечных точках между дугами и между дугой и окружностью. Добавленные ограничения можно удалить через **Remove constraint / dimension**.

Дугу можно связать с эллипсом касательностью или сопряжением по кривизне: точка контакта задаётся параметрическим углом эллипса в градусах. Доступны также концентричность и равенство радиусов дуги с другой дугой или окружностью.

Параметрический эскиз поддерживает кубический сплайн Безье по четырём управляющим точкам, интерполяционный кубический сплайн по точкам, открытые NURBS степени 2–5 с весами и узлами и периодические NURBS с неравномерными интервалами и кратными узлами. В редакторе их можно добавить из существующих именованных точек и перетаскивать эти точки; веса, узлы и интервалы узлов редактируются в параметрах операции. Для конца сплайна доступны касательное сопряжение и сопряжение по кривизне с другими кривыми и участками пазов. Точка контакта на пазу или периодической NURBS задаётся параметром от 0 до 1. Доступна привязка точки к отрезку, окружности или заданному параметру сплайна. Другие виды сплайнов и произвольные составные пазы пока не поддерживаются.

Кнопки **Draw Bezier**, **Draw fit spline**, **Draw NURBS** и **Draw periodic NURBS** позволяют задавать точки щелчками в параметрическом редакторе. Для сплайна по точкам и NURBS построение завершается Enter или правой кнопкой, Esc отменяет его; сплайн Безье создаётся после четырёх точек. Флажок **Construction** делает новую кривую вспомогательной. Веса, степень, узлы или периодические интервалы можно изменить через **Edit NURBS weights and knots**; проверка перестроения выполняется до применения.

Связь **Curvature between curves** задаёт сопряжение по кривизне между двумя поддерживаемыми кривыми в выбранных параметрах от 0 до 1. Для окружности и эллипса параметр задаёт долю полного оборота. В узлах с разрывом касательной или кривизны связь отклоняется. Границы пазов и отдельные части многосегментной линии в этом общем диалоге не выбираются; для пазов доступны отдельные связи.

Команда **Add polyline slot** создаёт составной паз постоянной ширины вдоль ломаной из именованных точек. Контур строится объединением участков с круглыми окончаниями. Для сопряжения дуги или сплайна выбираются исходный участок и сторона или окончание; контакт, скрытый внутри объединённого паза, отклоняется при перестроении. **Add arc slot** создаёт паз вдоль круговой дуги по трём точкам. **Add spline slot** строит паз по открытой кривой Безье, интерполяционному сплайну или NURBS; путь рекомендуется сделать вспомогательной геометрией. Стороны и окончания этих пазов доступны для касательных связей и сопряжения по кривизне. Пазы по другим произвольным кривым пока не поддерживаются.

**Add composite curve slot** создаёт паз по упорядоченной открытой цепочке отрезков, круговых дуг и открытых сплайнов. Стыки должны иметь совпадающие точки и направления касательных; решатель учитывает эти связи при редактировании. Для связи по кривизне в стыке дополнительно проверяется её непрерывность. Доступна привязка точки к выбранному параметру границы паза. Замкнутые и разветвлённые траектории, а также все виды произвольных кривых пока не поддерживаются.

Параметрический режим поддерживает ограниченный набор операций и отличается от обычного режима построения: не все команды обычного режима доступны внутри него. Ссылки на грани и рёбра пока основаны на геометрических признаках; при неоднозначности или изменении топологии может потребоваться повторный выбор. Полноценное устойчивое именование топологии ещё не реализовано.

## Файлы проекта

Команды **Save solid model snapshot** и **Open solid model snapshot** работают с файлами `.fcad`. Снимок содержит геометрию тела, историю и вспомогательные плоскости; для параметрической модели также сохраняется граф операций. Для сохранения необходимо сначала создать твёрдое тело. Незавершённый эскиз без тела сохранить как полноценный проект пока нельзя.

Для обмена геометрией используйте **Import STEP as new body** и **Export STEP / STL**. Форматы STEP и STL предназначены для обмена геометрией, а не для сохранения редактируемой истории FluentCAD.

## Тесты

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -q
```

Тесты проверяют геометрические операции, ограничения, перестроение параметрического графа и сохранение данных. Они не заменяют проверку интерактивной работы в окне приложения.

## Автоматические сборки

GitHub Actions запускает тесты и собирает архивы для Windows x86-64 и Linux x86-64 при отправке изменений, создании pull request и ручном запуске. Готовые архивы находятся в разделе **Actions** выбранного запуска, в блоке **Artifacts**. Запуск приложения и проверка работы мышью в этих тестах не выполняются: собранный исполняемый файл отдельно проверяется без открытия окна.

Для публикации сборок в **Releases** отправьте тег версии, например:

```sh
git tag v0.1.0
git push origin v0.1.0
```

После успешной сборки обеих платформ workflow создаст релиз с архивами и автоматически сформированным описанием. Повторный запуск для существующего релиза обновит его архивы. Для публикации в настройках репозитория должны быть включены GitHub Actions и разрешена запись для `GITHUB_TOKEN`. Распакуйте архив целиком; в Windows запускайте `FluentCAD/FluentCAD.exe`, в Linux — `FluentCAD/FluentCAD`. Сборка Linux рассчитана на совместимые системы x86-64 с графическим окружением и не является AppImage.

## Структура проекта

- `app/main.py` — запуск приложения.
- `app/UI/main/` — окна и элементы интерфейса.
- `app/UI/model/` — инструменты эскиза, геометрические операции, история и параметрический граф.
- `app/utils/` — вспомогательные алгоритмы.
- `tests/` — автоматические тесты.
