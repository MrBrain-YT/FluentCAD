# FluentCAD

FluentCAD — разрабатываемая настольная CAD-программа для создания эскизов и твёрдых тел. Интерфейс построен на PySide6, трёхмерная сцена использует PyVista и VTK, а геометрические операции выполняются с помощью build123d и Open CASCADE.

Проект находится в разработке: часть инструментов и параметрической истории уже доступна, но функциональность и устойчивость работы ещё не соответствуют полноценным промышленным CAD-системам.

## Возможности

- Создание эскизов на базовых плоскостях и плоских гранях, работа с линиями, окружностями, дугами и другими элементами.
- Сетка и привязки при построении; поиск замкнутых контуров для операций с телами.
- Создание и изменение твёрдых тел, включая выдавливание, вращение, примитивы, скругления и фаски, перемещение, масштабирование и массивы.
- Ограничения и размеры эскиза, численный решатель и отображение состояния ограничений. Доступные связи зависят от режима редактирования.
- История операций и Undo / Redo; отдельный параметрический режим с зависимостями, именованными параметрами, выражениями и перестроением модели.
- Сохранение снимка модели в `.fcad`, импорт STEP, экспорт STEP и STL.

## Установка и запуск

Требуется Python 3.12 или новее. Проект разрабатывается и проверяется в Windows. Команды ниже выполняются в PowerShell из корневой папки проекта:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app\main.py
```

При установленном [uv](https://docs.astral.sh/uv/) зависимости можно установить из lock-файла:

```powershell
uv sync
uv run python app/main.py
```

Запускайте приложение из корневой папки проекта: некоторые ресурсы интерфейса загружаются по относительным путям. Точка входа `fluentcad` в текущем пакете пока является заглушкой; для запуска используйте `app/main.py`.

## Параметрическая модель и Timeline

Файловые команды, отмена и повтор доступны в верхней полосе. Нажмите **S**, чтобы найти команду текущего режима. Вкладка **Sketch** появляется при создании или редактировании эскиза. Слева находится дерево модели, его можно свернуть кнопкой в верхней полосе или сочетанием **Ctrl+Alt+B**.

Внизу сцены находится панель навигации с подгонкой вида, проекцией, стандартными видами и настройками отображения. Режим **Theme: System / Light / Dark** сохраняется между запусками и меняет оформление элементов управления и фон сцены. **Ctrl+Alt+N** скрывает или возвращает панель навигации.

Перетаскивайте навигационный куб в правом верхнем углу левой кнопкой мыши для свободного вращения модели. Щелчок по грани, ребру или углу плавно переключает вид и сохраняет центр и масштаб. Кнопка **Home** плавно возвращает стандартную изометрию. В режиме эскиза куб сохраняет привязку камеры к плоскости.

В новом документе обычная кнопка **Create sketch** создаёт параметрический эскиз: выберите плоскость, нарисуйте геометрию и нажмите кнопку завершения эскиза. Замкнутые области появятся в сцене; щёлкните нужную область и нажмите **Extrude**, затем настройте операцию и подтвердите её. Эскиз и выдавливание появятся на Timeline. Чтобы повторно показать области эскиза, нажмите его правой кнопкой на Timeline и выберите **Show sketch profiles**.

Для выдавливания нескольких областей одного эскиза выделите их с **Ctrl** перед запуском **Extrude** или щёлкайте по областям, пока открыта панель команды. Можно также заранее выделить плоские грани в одной плоскости. Смежные выдавленные области объединяются, а раздельные в режиме **New body** создают отдельные тела. Вся операция записывается одним шагом в Timeline.

В **Extrude → Extent → To Object** выберите **Face** или **Body**, нажмите **Select in scene** и щёлкните по грани. Для **Plane** выберите конструктивную плоскость из списка. **Flip direction** меняет сторону выдавливания. Вытягивание до объекта идёт в одну сторону, и цель должна перекрывать окончание всех выбранных профилей. Для тела используется ближайшая граница в заданном направлении.

Для вращения замкнутой области нажмите **Revolve**. Помимо горизонтальной и вертикальной осей эскиза доступны **Straight sketch line** и **Straight edge or cylindrical face**. Нажмите **Select in scene** и щёлкните по сегменту эскиза, прямому ребру или цилиндрической грани. Угол задаётся числом или угловым манипулятором. Для параметрической геометрии Timeline сохраняет ссылку на выбранную ось, чтобы вращение перестраивалось после её изменения.

Для редактирования существующего эскиза в основной сцене выберите в его контекстном меню **Edit sketch in scene**. Перетаскивайте синие именованные точки и оранжевые ручки радиуса окружностей; геометрия пересчитывается после отпускания мыши. Можно добавлять геометрию инструментами панели и задавать связи через **Constraints**. Кнопка завершения применяет изменения и перестраивает зависимые операции; Esc при неактивном инструменте отменяет редактирование. Редактор в отдельном окне пока сохранён как запасной вариант.

В группе **CREATE ▾** эскиза доступны **Bezier spline**, **Fit-point spline**, **NURBS** и **Periodic NURBS**. Задавайте точки щелчками в сцене: Безье завершается после четырёх точек, остальные — клавишей Enter. После завершения можно перемещать точки. Кнопка **NURBS parameters** открывает настройку степени, весов и узлов, а **Remove constraint** удаляет выбранную связь. Типы связей и элементы пока выбираются в диалогах по именам, не щелчками по геометрии.

Там же находятся команды **Polyline slot**, **Arc slot**, **Spline slot** и **Composite curve slot**. Настройки и связи применяются к копии эскиза в сцене: окончательное перестроение модели происходит при завершении эскиза, а Esc при неактивном инструменте отменяет изменения.

В активном параметрическом эскизе в меню **Modify ▾** доступны **Trim**, **Extend** и **Offset copy**. Наведите курсор на геометрию для предпросмотра и щёлкните, чтобы применить правку. **Trim** удаляет подсвеченный участок между пересечениями, а при отсутствии разделяющих пересечений — весь сегмент или окружность. **Extend** удлиняет ближайший к курсору конец до границы. **Offset copy** создаёт независимую копию одного сегмента, дуги или окружности.

Для эллиптических дуг и сплайнов **Trim** сохраняет выбранные диапазоны исходной кривой, а **Extend** продолжает открытую кривую до ближайшей границы. После применения сохраняются параметры эллипса или управляющие точки сплайна и найденные диапазоны.

**Modify ▾ → Offset** создаёт ассоциативное смещение из отрезков, круговых и эллиптических дуг, сплайнов, а также из отдельных замкнутых кривых. С включённым **Chain selection** наведите курсор и щёлкните по любому сегменту связной цепочки. Чтобы выбрать часть цепочки или пройти разветвление, выключите **Chain selection** и укажите нужные сегменты щелчками. Поле **Offset** обновляет предпросмотр выбранной цепочки. Для замкнутой цепочки положительное значение смещает контур наружу, а для открытой — влево по направлению выбранного первым сегмента. Нажмите **Apply Offset** или **Enter**, затем **Finish Sketch**.

Для внешних углов выберите **Automatic**, **Bevel** или **Round**. **Automatic** соединяет отрезки и круговые дуги до пересечения и ставит фаску на внешних углах цепочек со сплайнами или эллипсами. **Bevel** соединяет смещённые сегменты прямой, а **Round** — касательной круговой дугой с радиусом, равным модулю смещения. Внутренние углы подрезаются до пересечения. Смена режима сразу обновляет предпросмотр выбранной цепочки.

Смещение и режим углов сохраняются в `.fcad` и перестраиваются по решённой геометрии источников. Смещённые эллипсы и сплайны представлены B-сплайнами с допуском ядра. Смещённые границы участвуют в построении профилей. Если правка разрывает исходную цепочку или сводит смещение к вырожденному контуру, FluentCAD отклоняет правку при перестроении.

В **Modify ▾ → Fillet / Chamfer** выберите два сегмента с общим концом. Для **Fillet** задайте радиус, для **Chamfer** — одинаковый отступ вдоль обоих сегментов. Наведение на второй сегмент показывает результат, а щелчок фиксирует выбор для точной настройки размера. Нажмите **Apply Corner** или **Enter**, затем **Finish Sketch**. Угол сохраняет связь с исходными сегментами и перестраивается при изменении эскиза, если размер по-прежнему помещается.

В **Modify ▾ → Mirror** щелчками выберите кривые и точки. Нажмите **Select Axis** или **Enter**, наведите курсор на прямой сегмент, чтобы увидеть отражение, и щёлкните по оси. **Apply Mirror** или **Enter** применяет отражение к эскизу. Кривые перестраиваются при изменении источника или оси. Отражённая вспомогательная геометрия остаётся вспомогательной, а совпадающие с источником отражения не дублируются.

В **Modify ▾ → Move / Copy** выберите кривые и точки щелчками. Щелчок по сегменту полилинии выбирает всю полилинию. Введите **ΔX**, **ΔY** и угол в градусах. Поворот выполняется вокруг начала координат эскиза, затем применяется смещение по его осям. Включите **Create Copy** для создания независимой копии со связями между выбранными объектами. Предпросмотр учитывает решатель и зависимые операции. При конфликте инструмент показывает причину и сохраняет текущее состояние. **Apply Transform** или **Enter** применяет преобразование, а **Finish Sketch** сохраняет изменения в модели.

В **Modify ▾ → Scale** выберите кривые и точки, нажмите **Select Center** и укажите центр в сцене. Можно выбрать существующую точку или место на плоскости эскиза с учётом настроек привязки. Введите положительный **Factor** и проверьте предпросмотр. Размеры между выбранными объектами масштабируются вместе с геометрией, включая размеры, заданные выражениями. **Apply Scale** или **Enter** применяет изменение к эскизу.

В **Modify ▾ → Rectangular Pattern** или **Circular Pattern** выберите кривые и точки. Для прямоугольного массива нажмите **Select Direction** и укажите прямой сегмент. Вторая ось перпендикулярна первой в плоскости эскиза. Задайте количество и шаг по обеим осям. Для кругового массива нажмите **Select Center**, укажите точку или место на плоскости, затем задайте количество и угол. Количество включает исходный экземпляр. Предпросмотр обновляется при вводе, а **Apply Pattern** применяет массив. Экземпляры сохраняют связь с источником и выбранным сегментом или именованной точкой центра.

В рабочей области **Solid** команда **Create ▾ → Sweep** создаёт новое тело по замкнутому профилю. Выберите область профиля, затем отметьте сегменты связной цепочки в сцене. Повторный щелчок снимает выбор сегмента. Один конец цепочки должен лежать на плоскости профиля, а траектория в этой точке должна выходить из плоскости. Проверьте предпросмотр и нажмите **OK**. Операция сохраняет ссылки на профиль и сегменты траектории.

В рабочей области **Solid** команда **Create ▾ → Loft** создаёт новое тело через два или более замкнутых профиля. Выберите профили в сцене и настройте порядок сечений кнопками **Move Up** и **Move Down**. Повторный щелчок по профилю или кнопка **Remove** убирает его из списка. Предпросмотр обновляется при изменении списка. После нажатия **OK** Loft хранит порядок и ссылки на исходные профили.

Чтобы изменить существующий Loft, дважды щёлкните по нему в таймлайне или выберите **Edit Loft** в контекстном меню. В сцене доступна геометрия, созданная до этой операции. Редактор загружает сохранённые сечения, направляющие, ручные пары отверстий и настройки G1/G2. **OK** применяет правку к той же операции и перестраивает последующие операции. Если зависимая операция не перестраивается, редактор показывает причину и сохраняет предпросмотр Loft. **Cancel** возвращает модель до правки.

Включите **Select Guides**, чтобы добавить направляющие Loft щелчками в сцене. Каждая направляющая должна быть открытой кривой и проходить через контур каждого сечения ровно один раз в порядке списка. Выбирайте сечения с одинаковым числом отверстий. Направляющую можно привязать к внешнему контуру или к одному отверстию во всех сечениях. Повторный щелчок по кривой снимает выбор. Изменение профиля или направляющей перестраивает тело, если контакты с контурами сохраняются.

Включите **Match Holes** и выберите пару соседних сечений. Щёлкните по контуру отверстия в первом сечении пары, затем по соответствующему контуру во втором. Loft обновит предпросмотр и подберёт оставшиеся пары автоматически. Чтобы заменить пару, выберите её в списке и нажмите **Remove Match**. Ручные пары и условия G1/G2 сохраняются при правке профилей, пока исходные контуры и опоры однозначно определяются. Направляющие должны проходить через те же отверстия, что и ручные пары.

Для **First section** и **Last section** выберите **Outer contour** или нужное отверстие **Hole 1**, **Hole 2** и далее. Выбранный контур подсвечивается в сцене. Для каждого контура доступны **Position**, **Tangent (G1)** и **Curvature (G2)**. Для G1 или G2 нажмите **Pick Face** и щёлкните по опорной грани тела. Кромка грани должна совпадать с выбранным контуром. Предпросмотр учитывает все настроенные контуры, а Loft перестраивается при изменении их опорных граней.

Для несоосного или некруглого контура с G1/G2 выберите минимум две независимые направляющие и плоскую, цилиндрическую или полученную выдавливанием боковую грань. На концах направляющие должны удовлетворять выбранному условию опоры. У цилиндрических и выдавленных граней они должны выходить вдоль образующих. Для соосных круговых контуров доступны также конические и сферические опоры с направляющими, задающими общий профиль вращения.

**Esc** завершает текущий инструмент. Уже применённые правки сохраняются в редактируемом эскизе, а **Finish Sketch** применяет их к модели. Trim и Extend защищают сегменты с ограничениями, выражениями и зависимыми траекториями пазов. Если правка лишает операцию её профиля, FluentCAD отклоняет её до изменения модели. Для эскиза на старой модели из снимков сначала используйте **Convert legacy model to parametric**.

В меню **Project / Include ▾** команда **Project** переносит выбранное ребро или границы выбранной грани на плоскость эскиза. **Intersect** строит сечение выбранного тела, грани или ребра. Для выбора появляется полупрозрачный результат предшествующей операции с твёрдыми телами в Timeline. Наведите курсор на нужную геометрию для предпросмотра и щёлкните, чтобы сохранить связь. Для сечения тела щёлкните по одной из его граней. **Enter** или **Esc** завершает инструмент, а **Finish Sketch** применяет изменения.

- **Project body silhouette** — выберите предыдущую операцию с телом, затем наведите курсор на грань нужного тела и щёлкните. Проекция строится вдоль нормали эскиза. Внутренние видимые рёбра отбрасываются, а просветы на всю глубину остаются контурами отверстий.
- **Project curves from another sketch** — выберите исходный эскиз, затем наведите курсор на подсвеченную кривую источника и щёлкните. Можно последовательно выбрать несколько кривых одного эскиза. Проекция доступна и в документе, где пока есть только эскизы.
- **Include 3D Geometry — Edges / Sketch curves** — выберите предыдущую операцию с телом или исходный эскиз, затем наведите курсор на ребро или кривую и щёлкните. Предпросмотр и результат сохраняют исходное положение в 3D. После **Finish Sketch** кривые видны в сцене, а их видимость переключается вместе с эскизом в дереве. Для обзора глубины при редактировании вращайте сцену с зажатой клавишей **Ctrl**.

Включённые 3D-кривые обновляются при изменении источника. Кривые, лежащие в плоскости эскиза, участвуют в построении профилей, а остальные остаются пространственной геометрией. При потере связи и после **Break Link** последняя корректная 3D-геометрия сохраняется в координатах модели.

В редакторе связанные кривые и точки в плоскости эскиза показаны фиолетовым, а пространственные кривые вне плоскости — бирюзовым. Связи сохраняются в `.fcad` и перестраиваются после изменения исходной модели или плоскости эскиза.

При потере источника, исчезновении сечения или изменении состава контура эскиз сохраняет последнюю корректную геометрию. Потерянные кривые выделяются оранжевым, а в Timeline появляется отметка **lost link(s)**. Откройте **Relink sketch geometry…** из Timeline или **Project / Include ▾ → Relink…** в редакторе, выберите связь и предыдущую операцию, затем наведите курсор и щёлкните по новому источнику в сцене. Если новая граница меняет зависимый профиль настолько, что его нельзя однозначно найти, потребуется подавить зависимую операцию и выбрать профиль повторно.

**Project / Include ▾ → Break Link…** сохраняет точные кривые и точки и удаляет зависимость от источника. Плоские кривые остаются частью профилей, а пространственные сохраняют координаты модели. Для кривых в плоскости доступны привязки. Нажмите **Finish Sketch**, чтобы применить Relink или Break Link к модели.

Перетаскивание средней кнопкой мыши сдвигает вид. **Shift + средняя кнопка** вращает модель, а колёсико масштабирует к курсору. При редактировании эскиза оба жеста средней кнопкой сдвигают вид вдоль плоскости эскиза. Зум остаётся привязан к курсору, а вид сохраняет ортографическую проекцию на плоскость.

Эскиз на плоской грани параметрического тела хранит ссылку на эту грань. Если после перестроения грань нельзя однозначно найти, операцию нужно переопределить. Эллиптические дуги обычного эскиза сохраняются в параметрической истории.

Команда **FILE ▾ → Convert legacy model to parametric** переносит существующее тело старой модели в базовую неизменяемую операцию. Исходные эскизы и параметры операций из снимка восстановить нельзя; сохранённая история снимков доступна после отмены преобразования через Undo. Преобразованную модель можно сохранить в `.fcad` и добавлять к её телу новые параметрические операции.

Для поддерживаемых профилей выдавливание запоминает происхождение границ и ищет те же области после перестроения. Если соответствие неоднозначно, изменение отклоняется. Чтобы заменить профили после изменения контура, подавите выдавливание в Timeline, измените эскиз и выберите **Reselect extrusion profile** в меню операции. Для одной области достаточно щелчка. Если операция использовала несколько областей, выделите их щелчками и подтвердите выбор клавишей **Enter**. Затем снимите подавление. Для некоторых типов геометрии сопоставление ограничено проверкой количества профилей.

В группе **File** команда **New parametric model** создаёт пример: плоскость, прямоугольный эскиз и выдавливание с параметрами `width`, `height` и `depth`. **Edit named parameters** изменяет параметры, а **Add parametric feature** добавляет операцию и позволяет указать её параметры в JSON.

Контекстное меню операции на Timeline позволяет изменить параметры, переименовать, подавить или переместить операцию. Для эскиза типа `planar_sketch` с именованными точками доступны редактирование в сцене и отдельное окно. Изменения сначала проверяются перестроением модели и применяются после завершения редактирования.

В редакторе эскиза выберите **Dimension ▾ → Sketch Dimension** и щёлкните по отрезку, двум точкам, окружности или дуге. Для окружности команда предлагает диаметр, для дуги — радиус. В меню **Dimension** можно также явно выбрать горизонтальное или вертикальное расстояние, угол между двумя отрезками, радиус или диаметр.

Переместите курсор, чтобы увидеть размерную линию, и щёлкните для размещения подписи. В поле значения можно ввести число или выражение с именованными параметрами. Эскиз обновляется при вводе корректного значения. Чтобы изменить существующий размер, активируйте **Sketch Dimension** и щёлкните по его подписи. **Finish Sketch** применяет изменение к модели и её зависимым операциям.

В меню **Constraints** выберите геометрическое ограничение и укажите точки или кривые прямо в сцене. При наведении на последний объект появится предпросмотр решения. Щелчок применяет ограничение к редактируемому эскизу. **Esc** закрывает инструмент, а **Finish Sketch** применяет изменения к модели. При конфликте в строке состояния появится причина, и эскиз сохранит текущее состояние.

Для касания и сопряжения по кривизне щёлкайте по дуге или открытому сплайну ближе к нужному концу. При сопряжении сплайна с окружностью щелчок по окружности задаёт место контакта. **Constraints → More constraints…** открывает выбор по списку с дополнительными вариантами, а **Remove constraint…** удаляет выбранную связь.

В этом редакторе доступны связи совпадения, горизонтальности, вертикальности и фиксации точек, параллельности, перпендикулярности, коллинеарности и равенства длин отрезков, симметрии и середины, расстояния и угол. Для окружностей доступны радиус и диаметр, концентричность, равенство радиусов и касание к прямой или другой окружности. Для дуг по трём точкам доступны радиус, диаметр и касание в выбранной конечной точке к отрезку, другой дуге или окружности. Сопряжение по кривизне поддерживается в выбранных конечных точках между дугами и между дугой и окружностью. Добавленные ограничения можно удалить через **Remove constraint / dimension**.

Дугу можно связать с эллипсом касательностью или сопряжением по кривизне: точка контакта задаётся параметрическим углом эллипса в градусах. Доступны также концентричность и равенство радиусов дуги с другой дугой или окружностью.

Параметрический эскиз поддерживает кубический сплайн Безье по четырём управляющим точкам, интерполяционный кубический сплайн по точкам, открытые NURBS степени 2–5 с весами и узлами и периодические NURBS с неравномерными интервалами и кратными узлами. В редакторе их можно добавить из существующих именованных точек и перетаскивать эти точки; веса, узлы и интервалы узлов редактируются в параметрах операции. Для конца сплайна доступны касательное сопряжение и сопряжение по кривизне с другими кривыми и участками пазов. Точка контакта на пазу или периодической NURBS задаётся параметром от 0 до 1. Доступна привязка точки к отрезку, окружности или заданному параметру сплайна. Другие виды сплайнов и произвольные составные пазы пока не поддерживаются.

Кнопки **Draw Bezier**, **Draw fit spline**, **Draw NURBS** и **Draw periodic NURBS** позволяют задавать точки щелчками в параметрическом редакторе. Для сплайна по точкам и NURBS построение завершается Enter или правой кнопкой, Esc отменяет его; сплайн Безье создаётся после четырёх точек. Флажок **Construction** делает новую кривую вспомогательной. Веса, степень, узлы или периодические интервалы можно изменить через **Edit NURBS weights and knots**; проверка перестроения выполняется до применения.

Связь **Curvature between curves** задаёт сопряжение по кривизне между двумя поддерживаемыми кривыми в выбранных параметрах от 0 до 1. Для окружности и эллипса параметр задаёт долю полного оборота. В узлах с разрывом касательной или кривизны связь отклоняется. Границы пазов и отдельные части многосегментной линии в этом общем диалоге не выбираются; для пазов доступны отдельные связи.

Команда **Add polyline slot** создаёт составной паз постоянной ширины вдоль ломаной из именованных точек. Контур строится объединением участков с круглыми окончаниями. Для сопряжения дуги или сплайна выбираются исходный участок и сторона или окончание; контакт, скрытый внутри объединённого паза, отклоняется при перестроении. **Add arc slot** создаёт паз вдоль круговой дуги по трём точкам. **Add spline slot** строит паз по открытой кривой Безье, интерполяционному сплайну или NURBS; путь рекомендуется сделать вспомогательной геометрией. Стороны и окончания этих пазов доступны для касательных связей и сопряжения по кривизне. Пазы по другим произвольным кривым пока не поддерживаются.

**Add composite curve slot** создаёт паз по упорядоченной открытой цепочке отрезков, круговых дуг и открытых сплайнов. Стыки должны иметь совпадающие точки и направления касательных; решатель учитывает эти связи при редактировании. Для связи по кривизне в стыке дополнительно проверяется её непрерывность. Доступна привязка точки к выбранному параметру границы паза. Замкнутые и разветвлённые траектории, а также все виды произвольных кривых пока не поддерживаются.

Параметрический режим поддерживает ограниченный набор операций и отличается от обычного режима построения: не все команды обычного режима доступны внутри него. Ссылки на грани и рёбра пока основаны на геометрических признаках; при неоднозначности или изменении топологии может потребоваться повторный выбор. Полноценное устойчивое именование топологии ещё не реализовано.

## Файлы проекта

Команды **File → Save model** и **File → Open model** работают с файлами `.fcad`. Параметрический документ можно сохранить сразу после **Finish Sketch**, до создания первого тела. После открытия эскиз доступен для редактирования из Timeline или дерева модели. Файл сохраняет параметры, ограничения, историю Undo / Redo и вспомогательные плоскости. Для старых моделей из снимков требуется твёрдое тело.

Для обмена геометрией используйте **Import STEP as new body** и **Export STEP / STL**. Форматы STEP и STL предназначены для обмена геометрией, а не для сохранения редактируемой истории FluentCAD.

## Тесты

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -q
```

Тесты проверяют геометрические операции, ограничения, перестроение параметрического графа и сохранение данных. Они не заменяют проверку интерактивной работы в окне приложения.

## Автоматические сборки

GitHub Actions запускает тесты и собирает архивы для Windows x86-64 и Linux x86-64 при отправке изменений, создании pull request и ручном запуске. Готовые архивы находятся в разделе **Actions** выбранного запуска, в блоке **Artifacts**. Запуск приложения и проверка работы мышью в этих тестах не выполняются: собранный исполняемый файл отдельно проверяется без открытия окна.

Для публикации сборок в **Releases** отправьте тег версии, например:

```sh
git tag v0.1.0
git push origin v0.1.0
```

После успешной сборки обеих платформ workflow создаст релиз с архивами и автоматически сформированным описанием. Повторный запуск для существующего релиза обновит его архивы. Для публикации в настройках репозитория должны быть включены GitHub Actions и разрешена запись для `GITHUB_TOKEN`. Распакуйте архив целиком; в Windows запускайте `FluentCAD/FluentCAD.exe`, в Linux — `FluentCAD/FluentCAD`. Сборка Linux рассчитана на совместимые системы x86-64 с графическим окружением и не является AppImage.

- `app/main.py` — запуск приложения.
